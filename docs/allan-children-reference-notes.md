# Allan Children Foundation Reference Review

## Scope and boundary

This review uses only the public site as a visual and interaction reference. PWLIF should not copy the Foundation's name, logo, photographs, personal stories, numerical claims, donation language, or safeguarding approach. PWLIF's existing private-by-default Sponsor Talent safeguards remain mandatory.

## Homepage observations — 20 August 2026

The homepage establishes a media-led editorial feel with a full-bleed hero photograph, an applied color overlay, compact top navigation, a high-contrast call-to-action, a slide counter, and a contained video prompt. It then transitions to large editorial headings, two-column image-and-copy compositions, framed informational modules, and repeated action prompts. Its hierarchy relies on large whitespace, oversized display typography, thin rules, high-contrast color blocks, and photography as the primary visual narrative.

PWLIF-compatible translation: retain PWLIF's navy, green, blue, gold, magenta, and cream palette; use consented, non-identifying visual media or abstractions; use a calm orientation CTA instead of a public donation mechanism; and reserve any Sponsor Talent image for explicit profile and photo publication opt-ins.

## Success Stories observations — 20 August 2026

The Success Stories page uses a narrow photo-led banner below the navigation, a restrained white editorial canvas, oversized handwritten-style thematic words, numbered sequential narrative modules, alternating image and text placement, and an outlined call-to-action. The visual pattern makes a long page feel structured without relying on dense card grids.

PWLIF-compatible translation: create a non-identifying “Sponsor Talent Pathways” or “Community Learning” editorial sequence with optional numbers, alternating imagery, controlled summaries, and a “Request a private conversation” call-to-action. Do not use identifiable child narratives, individual outcome claims, or public donations/reports.

## Initial reusable patterns

| Reference pattern | Original PWLIF application |
|---|---|
| Full-bleed visual hero with color veil | Consent-aware, non-identifying hero visual with PWLIF navy/green overlay and orientation CTA |
| Condensed top navigation with a standout primary action | Existing PWLIF navigation with “Book Sponsor Orientation” as the primary action |
| Oversized editorial type with thin accent rules | PWLIF display headings with brand colors, maintaining legibility and accessible contrast |
| Alternating numbered stories | Optional Sponsor Talent pathway sections using safe, approved summaries only |
| Image-forward storytelling | Media library with field-level visibility and public/private delivery boundaries |

## News & Stories observations — 20 August 2026

The News & Stories page continues the same banner treatment and then uses a clear editorial introduction followed by a compact in-page category menu and long-form image-and-text story modules. This offers a useful pattern for organizing a growing media archive: a landing introduction, topic filters, and individual entries with deliberate visual rhythm rather than a crowded gallery.

PWLIF-compatible translation: a future “Foundation Updates” or “Community Learning” archive can use categories and modular feature stories, but must exclude names, identifiable images, sensitive personal circumstances, fabricated impact figures, financial/transparency-report material, and calls to publicly sponsor a child. Safe content should be limited to approved, non-identifying media and summaries, with private follow-up handled through the orientation workflow.
